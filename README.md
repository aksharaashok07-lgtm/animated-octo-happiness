# Python Programs



This is a repository containing basic Python programs for practice and learning. I am using these basic programs to develop a better understanding of Git and GitHub.



##### **About the Programs:**



1. **Calculator:**

This code uses if-elif-else conditional statements to add, subtract, multiply or divide the numbers provided by the user as input.



2\. **Factorial:**

A factorial of a number is the product of all the positive integers from 1 to the number. This code uses looping to find the factorial of a number which a user provides as input. 



3\. **Fibonacci Series:**

The Fibonacci series is a sequence where each number is generated by adding the two previous numbers. For example : 1 ,1 ,2 ,3 ,5 ,8 ,etc. This code uses looping and variable assignment to generate the Fibonacci sequence up to the number of terms the user provides as input. 



4\. **Prime Number:**

This code uses conditional statements to find whether a given number is prime or not.
